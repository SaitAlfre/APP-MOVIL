# Capturas del tablero — evidencia pendiente

No hay capturas operativas nuevas en esta consolidación. Registrar URL del Project, fecha real, sprint y estado observado; no recrear imágenes de días pasados.

Al usarlo: guardar solo imágenes relevantes de inicio, día intermedio y cierre, por ejemplo `2026-10-23-S06-tablero.png`, con una entrada EV en el [índice](../../evidencias/README.md). Si una imagen es simulación de clase, rotularla como **EJERCICIO SIMULADO / REPRESENTACIÓN ACADÉMICA**.

Saneamiento: ocultar nombres/datos de productores, tokens y contactos; conservar un original autorizado fuera del paquete público si hace falta. Captura sin fecha/contexto no demuestra historial ni cumplimiento de WIP. Las 2–3 capturas de PR requeridas por F3 corresponden al PR real, no sustituyen las del tablero.
